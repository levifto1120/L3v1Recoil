## 💥 Features
- **100% Standalone:** Zero Python needed, pure C++ executable.
- **AI Emblem Scanner:** Auto-detects active operator and switches recoil profiles on spawn (supports stretched resolutions).
- **Auto-Updater:** Self-updates directly from GitHub on launch.
- **Weapon Sync:** Tuning shared guns (417, MPX, etc.) syncs across all operators automatically.
- **Tactical Macros:** Left/Right Drop Peek, Crouch Spam, and Lean Spam with adjustable sliders.
- **Key Unbinding:** Click `[X]` on any keybind to clear it to *Not Bound*.

## 📥 Quick Setup
1. Download `L3V1_Recoil_Release.zip` from [Releases](https://github.com/levifto1120/L3v1Recoil/releases/latest).
2. Extract the folder and run `L3V1_Recoil.exe` as **Administrator**.
3. Set Siege to **Borderless Windowed**.
4. Press **`'`** or your toggle hotkey to turn ON/OFF!
